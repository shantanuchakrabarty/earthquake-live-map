# earthquake-live-map

## Starting out
Planned tech stack: **HTML,CSS,JS**

## What I'm building

A simple webpage with a world map that :
1. Loads recent earthquakes from a public data source.
2. Plots each one as a marker, with size or colour based on magnitude and depth.
3. Shows details like place, time, magnitude and depth when you click or hover.
4. Stays current, so new quakes appear without a page refresh.

**Data Source** - USGS GeoJSON Feeds
**Map Library** - Leaflet
**Base map tiles** - OpenStreetMap (tentative)
